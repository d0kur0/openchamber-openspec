# OpenSpec Studio

Русский интерфейс по умолчанию, английский через переключатель. Стандартный OpenSpec CLI и артефакты
остаются источником данных. Цель: быстро найти изменение, понять стадию и перейти к
документам/следующему действию.

Два вида: горизонтальная доска с колонками стадий и компактный список. Поиск по ID, цели и области,
фильтр стадии, проблемных сводок; сортировка по названию, выполнению и остатку. Контролы не теряются
на узкой панели. Заголовок карточки — цель, технический ID виден отдельно. Светлая/тёмная тема и
фокус используют токены SDK. Без декоративных градиентов и лишних карточек вокруг карточек.

Настройки языка/вида/сортировки сохраняются через storage хоста. Переключение языка возвращает на
доску, не меняет файлы и не отправляет запросы агентам. При смене темы открытые документы не
перемонтируются.

Приёмка: оба языка, сохранение языка после перезагрузки, комбинированные фильтры/сброс, понятный
пустой результат, одинаковые карточки в обоих видах, кириллица/длинные названия, узкая панель и обе
темы. Next action сохраняет подготовку неотправленного запроса, не запускает агента при фильтрации.
Загрузка только по исходному/context событию и явному Refresh. Windows CLI adapter сохраняется.
Stale/unavailable не выдаются за стадии выполнения.
